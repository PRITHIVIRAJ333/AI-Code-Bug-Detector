# DEEP CODE GUARD

AI-powered source code bug detection system using Deep Learning.

## Features

- Deep Learning based bug classification
- PyTorch training
- ONNX lightweight deployment
- Python static code analysis
- Risk score
- Bug severity
- Confidence score
- Suggested fixes
- Responsive web interface

## Technologies

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Flask
- Python

Deep Learning:
- PyTorch
- Neural Network
- ONNX Runtime

Machine Learning:
- TF-IDF feature extraction

Deployment:
- Vercel

## Important

TensorFlow is not used in this project.

PyTorch is used only during model training.
The trained model is converted to ONNX for lightweight inference.
